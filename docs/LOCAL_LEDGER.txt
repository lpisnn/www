Local flip ledger notes: In the desktop app, open Flip Records and click “本地鸡腿账本”. Ledger transactions are stored in the local Electron runtime cache, scoped by a one-way token hash; no ledger upload is implemented. Flip history is fetched from Pocket48 only when the user explicitly clicks the read button. This feature is not available on the public web build. Runtime cache is local but not encrypted; use device encryption and avoid shared computers.
